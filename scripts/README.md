# Scripts de apoio

Os scripts são auxiliares e não substituem a configuração nativa da GPMC quando ela atender ao requisito.

| Diretório | Scripts |
|---|---|
| `endpoints/` | Wallpaper e configurações de estação. |
| `impressoras/` | Instalação ou mapeamento de impressoras. |
| `arquivos/` | Distribuição e atualização de arquivos gerenciados. |

Todos os scripts devem receber caminhos e parâmetros explicitamente, evitar credenciais embutidas e documentar validação e rollback.
