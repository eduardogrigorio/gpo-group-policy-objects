# Scripts de endpoints

Scripts auxiliares para configurações aplicadas a estações Windows, como wallpaper e outras preferências de experiência do usuário.

## Conteúdo atual

- `Set-Wallpaper.ps1`: valida e aplica um wallpaper informado por parâmetro.

Execute primeiro em uma estação de homologação e use caminhos UNC com permissão de leitura. Não embuta credenciais ou caminhos reais de produção no script.
