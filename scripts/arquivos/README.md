# Scripts de arquivos

Scripts auxiliares para distribuição de arquivos não secretos a endpoints.

## Conteúdo atual

- `Copy-ManagedFile.ps1`: copia um arquivo para o destino usando um arquivo temporário e substituição controlada.

Não use esta área para senhas, tokens, chaves privadas ou dados pessoais. Valide a origem, permissões, hash e rollback antes da produção.
