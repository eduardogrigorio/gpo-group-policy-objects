# Backups de GPO

Este diretório é reservado para uso local ou em cópias controladas de backups de GPO. Backups reais podem conter nomes de domínio, SIDs, caminhos internos e configurações da infraestrutura.

Por padrão, o conteúdo é ignorado pelo Git. Não publique backups de produção neste repositório público sem sanitização, autorização e revisão de segurança.

O arquivo `.gitkeep` mantém o diretório na estrutura do projeto.
